# 结构编辑中的公式引用

`rewriteFormulaReferences(formula, { formulaSheetName, targetSheetName, edit })` 是无副作用的公式文本转换。`StructureEdit` 包含 `axis: 'row' | 'column'`、`kind: 'insert' | 'delete'`、零基 `index` 和正整数 `count`。插入发生在 `index` 前；删除区间为 `[index, index + count)`。接口不移动单元格，也不修改工作簿，调用方应先完成所有重写和尺寸检查，再提交整个结构事务。

- 支持引擎的 A1、`$A$1`、`A$1`、`$A1` 单格和矩形范围引用。结构编辑会移动 `$` 锚定引用；这是行列结构变化，与复制公式时的相对引用平移不同。
- 不带表名的引用仅在公式所在表等于目标表时重写；显式表名按大小写不敏感方式匹配目标表。单引号表名及内部双单引号转义保留原文本。区域右端省略表名时继承左端表名；两个显式端点必须指向同一表。
- 插入在范围首成员之前时整体平移；插入发生在范围内部时扩大范围；在最后成员之后插入不扩大范围。例如在零基行 2 插入一行，`A2:A5` 变成 `A2:A6`，但在零基行 5 插入保持不变。
- 删除范围的一部分后保留未删除成员并收缩边界；删除所有成员后整个引用变成 `#REF!`。单格引用被删除也变成 `#REF!`。倒序范围保留倒序，单行/单列收缩后仍保留两个端点形式。
- 重写后任一目标引用超过 Excel 上限（1,048,576 行、16,384 列）会抛出 `RangeError`，供宿主原子拒绝事务。未指向目标表的边界引用不因本次操作而报超限。
- 双引号字符串、公式错误字面量、函数名、数值和非 A1 标识符原样保留；只替换引用坐标文本。非公式文本原样返回，未改变的公式保持其空白、大小写、引号和分隔符。

外部工作簿引用、3D 表范围、结构化表引用、整行/整列范围以及无法安全识别的区域语法会抛出 `SyntaxError`。这些检测不进入字符串字面量；例如 `"Table[Column]"` 不会被当作引用。不支持的引用即使未指向目标表也明确拒绝，避免宿主错误地报告结构编辑已安全完成。未闭合引号也拒绝。该模块是受支持公式引用的结构重写器，不是通用 Excel 公式兼容解析器；公式计算错误仍由计算引擎处理。

单引号仅用于显式表名前缀（如 `'Data'!A1`）；裸单引号值或坐标（如 `='A1'`、`=SUM('A1':'A3')`）明确拒绝。即使旧计算器碰巧接受此类非标准写法，也不能在结构编辑时静默跳过。隐式交集 `@`、动态数组溢出 `A1#`、数组常量 `{}` 等尚未支持的语法同样拒绝。合法错误字面量（如 `#REF!`、`#DIV/0!`）继续原样保留，字符串内的这些字符不受影响。

`tests/formula-structure.test.ts` 覆盖绝对引用、跨表、转义表名、范围插删边界、倒序、整段删除、限值和不支持语法，并枚举范围删除结果与实际剩余成员集合进行核对。

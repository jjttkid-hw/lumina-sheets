# Canvas 单元格选项

v0.16 的工作空间和独立 JavaScript SDK 共用列表选择器。先配置 `list` 数据验证规则，选中范围中的一个单元格，再点击格内箭头或按 **Alt+↓**。独立报表示例的“订单填报”中，D2:D4 的状态可以直接选择。

## 输入与导航

- 搜索框按选项内容和类型筛选；方向键、Home/End 移动，Enter 提交，Esc 取消并返回表格。Tab 关闭浮层并保留浏览器的默认焦点导航，点击外部关闭。
- 文本、数字、布尔值保留原始类型，例如 `"1"` 和 `1` 是两项；文本用引号显示，首尾空格和换行可辨识。空字符串显示“空白”，不会把未提供的空白选项自动加入列表。
- 最多 1,000 个候选项使用固定行高的虚拟列表，仅挂载可见区域、缓冲行及键盘活动项。搜索和规则筛选处理选项，不展开规则覆盖的单元格矩形。
- 当前值以标记区分，重复选择同一原始值不提交补丁；选择其他值保留已有单元格样式，作为单格编辑进入原有验证、撤销/重做与保存流程。错误时保留浮层并显示提示。

## 规则与边界

候选按第一条匹配列表的顺序严格按类型去重，并满足该地址上全部匹配规则。多个列表取共同允许值，整数、小数和文本长度约束也参与筛选；空白遵循所有规则的 `allowBlank`。没有共同候选时仍可打开浮层查看空状态。

当前数据模型把以 `=` 开头的字符串解释为公式；这样的列表值不会作为字面文本选项提交，浮层显示排除数量。公式输入和计算结果验证仍由原有编辑器处理。本次未引入新的字面公式文本存储格式，也未扩大 XLSX 兼容范围。

只读/分页表、多个单元格的选区、正在编辑或等待筛选的视图不显示选择按钮。隐藏/合并单元格按可见投影定位并编辑原始合并锚点。按钮只在有足够可见空间的单元格片段内显示；浮层随视口边界调整上下位置，短视口可覆盖当前格。

切换工作簿、工作表、选区、规则、布局、缩放、滚动或外部数据版本后，已打开的浮层关闭，旧选择回调不再写入。候选提交时重新检查当前规则，然后交由工作空间/SDK 的正式编辑入口验证并保存。

本次自动验证覆盖规则、布局计算、组件事件和 SDK 集成；浏览器工具审批服务故障导致真实布局、焦点、触控和屏幕阅读器验收尚未完成。v0.18 工作空间单格修改采用补丁历史，结构操作仍保留快照；列表虚拟化不代表整体编辑、导入或公式计算获得新的性能保证。

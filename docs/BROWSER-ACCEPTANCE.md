## 最小回归步骤

关闭清理补充：保存失败后离开页面或销毁适配器，原生数据库连接仍应关闭；调用方收到原始保存错误，随后另一页面可以升级/打开并重试。若关闭本身失败，也不能遗留连接。真实页面刷新、升级阻塞和提示文案仍需浏览器验收。

快照整理失败补充：准备目标工作簿的损坏序号日志（字符串、负数或非安全整数），保存完整快照应失败并保留原快照、日志和待保存编辑；修复记录后重试成功。另验证游标删除/推进异常时整个事务回滚，不出现部分删除或保存成功。受控事务模型不替代原生 IndexedDB 原子性验收。

数据库重连失败补充：先成功打开数据库，再意外断开并令重连失败，保存应明确报错并保留编辑，不能切为仅内存后报告保存成功。恢复数据库后重试并刷新，核对编辑及旧工作簿保持。分别验证同步打开异常与异步请求失败；初次不可用的内存回退策略不变。此处受控请求回归不代表原生故障恢复已验收。

数据库关闭恢复补充：原生连接意外关闭后重试读取/保存，应重新建立连接；旧连接迟到的 close/versionchange 不得清除新连接。显式关闭适配器后再次使用应重开；原生事务中断时当前操作可失败，不能误报保存成功。受控事件测试不代表真实浏览器连接恢复已通过。

数据库升级补充：旧页面占用数据库时新页面升级应显示可重试错误；关闭旧页面后重试成功，旧请求迟到不会替换连接。versionchange 关闭旧连接，旧应用访问较新数据库应提示升级/刷新而非空内存工作空间。原生升级事务/多页阻塞仍待验。

原始日志救援补充：故意损坏日志令正常加载失败，下载备份核对 rawStorage 的快照/日志/辅助材料和警告；选择“原始快照（未重放日志）”恢复副本。一个存储拒绝读取时其他材料保持。验证原始存储未改写、未误报最新数据；真实 IndexedDB、下载和刷新待验。

日志结构补充：持久化日志含未知 kind、缺失 cell、非法地址或空/数组 changes 时，读取应明确失败并保留原存储；修复后重试恢复。批量修改遇到损坏记录不应部分提交。当前仅基本结构校验，不替代完整单元格/元数据语义验证；原生存储与恢复需实测。

日志身份补充：两页面生成相同 seq 的不同格编辑，核对 IndexedDB 键不同、重开均保留；重试同一条编辑保持 operationId 且不重复应用。同格同序号只承诺确定性顺序，协同冲突/并发快照整理仍未解决。原生多页测试待验。

日志时钟回拨补充：持久化日志序号高于新会话时钟起点时，读取工作簿后编辑同一格，刷新应保留新值；单本和目录读取均覆盖。异常序号明确失败且保留原存储。此项不提供跨页面冲突合并或原子序号分配，真实重启/时钟场景待验。

辅助卸载补充：批注/版本读取或保存等待期间卸载工作空间，旧请求成功/失败后不能再更新界面或显示提示。返回文档等待旧保存时再次离开，不应启动迟到读取；已发起保存仍正常完成。真实框架生命周期/导航与控制台需验收。

离页保护补充：编辑后立即刷新/关闭、保存失败及仅内存会话，核对原生提示；重试持久化成功后不应继续提示。批注/历史写入等待期间也需确认提示，卸载监听移除；分别检查有用户交互、移动端与页面恢复情形。不保证浏览器强制终止时弹窗或完成保存。

恢复搜索补充：在大备份中按名称/来源/版本/时间搜索，检查匹配数量；筛选隐藏当前项时必须重新选择，不能自动恢复第一条或错用筛选索引。无结果禁用恢复，清空搜索保留原选择；中文输入法和搜索 Enter 不应提交恢复。实际键盘、布局、焦点仍待验收。

历史快照恢复补充：当前工作簿损坏但 revisions 含有效旧版本时，导入恢复包并选择版本；另验只有旧版 history 的备份。核对来源/版本/时间、损坏条目可改选、恢复为新 ID 且保存刷新保持，历史列表/批注不回写，合计超过 1,000 条拒绝。实际窗口、键盘与文件流程待验。

辅助空值保真补充：真实库中将批注/历史载荷设为 null 或移除载荷字段，打开面板应提示错误并禁止写回；下载备份应保留原值且标记部分。真正不存在的键仍显示空列表并允许新增。检查刷新、修复后重试及原记录保持。

迁移标记竞态补充：页面 A 的初次标记读取结束后，页面 B 完成迁移并删除文档，再允许 A 取得写事务；核对 A 重新检查标记且不导回旧文档/辅助记录。观察原生事务失败时标记与内容共同回滚、修复后可重试；受控请求不能代替浏览器竞态验收。

主存储行损坏补充：在独立测试库准备有效工作簿和 null/标量快照、缺少 workbook 字段的行；启动核对有效文档和日志编辑可读，备份保留损坏条目，选取有效文档可恢复，原记录不变。当前仅模拟 IndexedDB 请求边界，原生读取/下载/刷新仍待验收。

旧版重复 ID 补充：同一旧列表准备同 ID 不同内容的两本工作簿，首次迁移核对只取首条且批注/历史不重复写；内存模式行为一致。下载恢复包确认原列表仍含所有版本，手动恢复第二版本为独立副本。真实事务执行与刷新验收待完成。

旧版迁移防覆盖补充：在无迁移标记、主存储已有新版正文/空批注/历史的情况下保留旧 localStorage，重启并核对原主记录不被覆盖、缺失键才迁入、原旧备份仍在。两个页面同时首次迁移并故障中止后重试，检查事务与标记一致性。受控事务回归不等于原生 IndexedDB 或多页验收。

启动主快照保护补充：主存储含与旧本地副本同 ID 的损坏工作簿时，启动应显示错误、备份和重试，不能将旧副本写回；修复后重试读取新版。部分损坏且有有效文档时，核对持续警告数量、正常编辑和顶部备份下载，原损坏条目保留。实际 IndexedDB、刷新、窄屏提示和下载尚待验收。

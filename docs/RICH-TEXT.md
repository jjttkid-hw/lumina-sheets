# 富文本片段

普通字符串单元格可包含 `richText` 片段，所有片段文字拼接须与 `value` 完全一致。最多 32,767 个片段及 32,767 个 UTF-16 字符；保留空片段。公式、数字和布尔值不接受片段，避免两种值来源冲突。

```js
grid.setCells([{ key: 'A1', cell: {
  value: '季度销售 增长',
  richText: [
    { text: '季度销售 ', style: { bold: true, fontSize: 18 } },
    { text: '增长', style: { color: '#198754', italic: true } },
  ],
} }]);
```

支持分段粗体、斜体、单下划线、删除线、六位 RGB 颜色、6–96 字号和字体名称。省略的属性继承单元格样式，显式 false 关闭继承的开关。字体名称最长 128 字符，字体由运行环境提供，不嵌入文件。工作空间工具栏的“局部格式”入口可选择已有文字并设置片段样式，也可以从 XLSX 导入或通过 SDK setCells 设置。

## 编辑与保存

JSON 校验、SDK load/setCells、工作空间补丁会检查片段和值一致性，保存隔离副本。普通输入、公式栏、列表选择、链接显示文字和 SDK setCell 改变文本时清除原片段；等值文字保留。撤销/重做恢复完整单元格，内部复制/填充保留片段，外部纯文本剪贴板不携带片段样式。排序即使文字相同也比较局部样式，片段随整行移动；行列结构操作和工作表重命名保留片段。

## 文件与显示

读取原始 XLSX sharedStrings/inlineStr 中的 r/rPr，保留运行片段，即使该格还有超链接；避免 ExcelJS 解码链接时扁平化显示文字。导出用 inlineStr 写回片段，保留单元格格式和链接关系；XML 转义保留空格、换行和特殊字符。空片段样式不能在合并从属格中被静默覆盖。

XLSX 主题/索引/透明色、双线/会计下划线、font scheme 等额外字体属性及拼音标注尚未实现；遇到这些富文本属性明确拒绝。不能将本子集视为完整 Excel 富文本兼容。真实 Excel 应用语料仍待验收。

Canvas 保持原有单行、单元格裁剪行为，逐段测量、绘制和对齐，自动列宽采样使用片段宽度。PDF 使用分段字号测量换行和行高后绘制，依然是栅格 PDF。不同片段之间不进行统一连字/字形塑形，复杂文字和双向排版尚未认证；这会影响跨片段字距。CSV 只输出拼接文字。

自动化覆盖实际 XLSX 字节往返、SDK 历史/隔离、排序、结构、列表编辑及 PDF 绘制路径；Canvas 测量测试使用受控上下文，不是浏览器视觉验收。真实浏览器绘制、剪贴板、输入法、PDF 下载与字体差异仍待验收。


## 工作空间局部格式编辑器

选中含普通文字的单元格，点击“局部格式”。在只读文字区用鼠标或 Shift + 方向键选中文字，再设置粗体/斜体/下划线/删除线开关、颜色、字号和字体名称；下方显示草稿预览。可以对同一选区连续设置属性，其他片段保持原样。恢复单元格样式会清除所选文字的局部属性，并继承单元格整体样式。

选区使用 textarea 的 UTF-16 坐标，CRLF/CR 换行映射回原文，不拆开代理对。组合字符/ZWJ 表情的完整字素边界尚未统一处理。此入口只修改片段格式，文字编辑仍通过表格和公式栏完成；空单元格、公式、数字与分页表不会隐式转换为富文本。保存一次产生一个可撤销补丁，保留链接、单元格样式等元数据；取消不保存，非法字号等错误保留草稿，旧对话框回调在关闭、成功保存或切换选区后拒绝。

工作空间、片段变换和对话框事件有自动回归；真实浏览器文字选区、焦点返回、键盘、窄屏及预览/Canvas 字体一致性尚待验收。


## 上标、下标与字体分类

片段样式新增 `verticalAlign: 'baseline' | 'superscript' | 'subscript'`，局部格式编辑器的“上下标”控件可设置正常、上标或下标。XLSX vertAlign 同名映射并往返保留；省略保持普通基线，显式 baseline 可恢复普通文字。字体分类 `fontFamilyClass` 接受 0–5，字符集代码 `charset` 接受 0–255，读取/写回 family、charset，不与 fontFamily 字体名称混淆；内部文字始终为 Unicode，charset 不用于重新解码。

Canvas 与 PDF 使用一致的显示约定：上下标字号为原字号的 65%，中心上/下偏移原字号的 30%，排版行高预留偏移空间；这不是 Excel 精确字体度量认证。字体分类与字符集仅保留文件语义，不控制浏览器字体选择。主题色和 scheme 字体关系仍未支持，未将主题关系折算为固定 RGB 冒充无损支持。


## XLSX 字符串编码

XLSX 片段文字和字体名称使用 ST_Xstring 单次转义解码；字面 `_x0041_` 不会被误当作 A。导出先保护转义形状的原文，再编码 XML 不允许的 UTF-16 单元、CR 和可能被 ExcelJS 去掉的 DEL；普通字符串格和链接显示文字也使用同一编码。富文本在生成初始文件时使用占位文字，随后从原片段写入编码后的 inlineStr，避免非法字符先进入 XML。

CRLF、孤立 CR、制表符、控制字符以及孤立代理单元的存储值能够按字节语义往返；后者在字体显示时可能呈现替代符号，存储保留不代表可视字符。原 XML 中 `&#13;` 在档案重写时也保持 CR。解码不会递归处理已经解码出的转义形状，片段边界保留。测试包含本产品读取和 ExcelJS 直接读取；尚不是 Excel 应用认证。

## 持久化更正

随后刷新 Safari 并等待导航完成，页面回到默认“行式明细”报表；订单填报编辑
没有保留。这符合当前接入示例的实现：它只在内存中保存 SDK 实例，启动脚本
会执行 `report('list')`。因此早期 r2/r15 记录中关于报表示例刷新恢复的描述已撤回，
不把它计入 v1.0 持久化门槛。工作空间的本地保存是另一条代码路径，不能外推到
此示例。

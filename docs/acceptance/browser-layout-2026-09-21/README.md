2026-09-21，在当前 0.29.0 生产站点和独立 SDK 示例加载真实 SDK，新增六组布局验收。Chrome 153.0.8010.50、Firefox 144.0.2、Playwright WebKit 26.0 各六组通过，共 **18 组通过**，最终页面异常和控制台错误均为零。原始结果和截图位于对应引擎目录。

## 实际检查

1. 隐藏第 3 行与 B 列：上下左右、Tab/Shift+Tab 跳过隐藏坐标；Shift+右箭头范围端点为 C2。
2. A2:C3 合并：鼠标点击 C3 的可见内部，实际选中和编辑主格 A2；四向离开/返回合并区域符合主格归属，C3 没有新增数据。
3. 冻结第一行：真实鼠标滚轮产生非零滚动，点击顶部仍命中 A1；F2 编辑冻结格后 A2 保持原值。
4. 百万逻辑行：通过 SDK 定位 C1000000，真实键盘 F2 编辑；活动格代理只有一个、末次绘制小于 1000 格；PageUp 和 Command+Home 导航有效。这是稀疏定位验收，不是百万实存格性能。
5. 改变第一行高度与 A 列宽度：相同鼠标坐标按新尺寸命中正确行列，布局撤销/重做后命中恢复。
6. 筛选：等待实际筛选完成提示消失，键盘跳过不匹配行；真实复制/粘贴结果只有两条可见记录。Delete 仅清除可见选区数据，隐藏的 omit 保留；一次撤销恢复。

## 初次失败与边界

Chrome 初次筛选导航超时：脚本在产品 180 ms 筛选防抖结束前按方向键，检查的坐标属于未筛选视图。最终脚本等待实际“正在筛选”提示结束；此项不验证筛选进行中导航应自动重定位。另初版夹具移除了示例 DOM，示例仍存活的回调访问不到节点产生异常；改为保留示例、创建独立宿主。初始失败报告保留在 chromium/before，不把脚本错误报告为产品修复。

本轮没有修改产品源代码、构建或版本，补充现有 72 组验收的布局范围。未证明原生 IME、正式 Safari、物理触控、屏幕阅读器或完整布局组合均已通过，仍没有 stable-release.json。此前完整自动化 162 文件 / 2296 项通过，本轮仅增加浏览器验收脚本，未重复全量单测。

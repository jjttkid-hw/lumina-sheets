## 实际检查

1. 选择“百万行分页数据”，页面显示 1,000,000 行 × 12 列；定位 `A1000000` 后 AX 选中单元格值为 `1000000`，缓存显示 `2/6`，编辑和结构按钮保持禁用。
2. 启动分页 CSV 导出，显示进度和已处理项目；点击“取消操作”后页面显示“操作已取消”，导出按钮恢复。
3. 选择“分页生成完整报表”，生成 200 行 × 4 列快照；选择 Excel，实际下载 `完整订单报表.xlsx`（10,415 字节）。
4. 通过 Safari 原生文件选择器重新导入该下载文件，定位 `C200`，结果为 `2990`；页面显示“报表已恢复”，数据为 200 行 × 16 列，证明下载文件可回读。

原始可访问性树、下载文件和结构化结果见同目录。此前 Safari r4 的结构撤销、筛选和公式状态仍保留；本记录补充分页和真实下载回读。

边界：这是 macOS Safari 实机验收，不等于 iOS 实体触控、VoiceOver 朗读、原生中文 IME 候选窗口、跨设备性能、完整 Excel/WPS 兼容或商业法律复核。

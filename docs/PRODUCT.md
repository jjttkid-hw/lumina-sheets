# 产品范围与商业路线

Lumina 的交付目标是一个高性能、可嵌入的前端 JavaScript 表格与报表 SDK。对照基准是 SpreadJS Report 性能页公开描述的 HTML5/JavaScript 布局、数据绑定、虚拟滚动、分片加载、复杂公式和客户端导出。官网的 CPU、网络和并发宣传数字没有公开测试条件，因此本项目不把它们当成本地性能保证。

## 当前可验收闭环

普通 JavaScript 页面可以挂载 `LuminaSpreadsheet`，生成列表、分组或交叉报表，绑定数组或 REST 分页数据，编辑静态报表，读取公式结果，并在浏览器内导出 XLSX、CSV、JSON 或有限制的 PDF。分页表格只加载视区页，缓存受 `maxPages` 限制；完整 CSV 走独立逐页扫描。

`examples/report.html` 的“行列编辑”工具可以插入、删除当前行列，查看公式与规则同步变化，并撤销整次操作；生产构建对应 `dist/sdk/example.html`。这些结构命令已接入 SDK 示例；0.27 起主工作空间也通过“行列”入口提供插入/删除及整次撤销。`/performance` 是实际数据测量页。性能页分别记录数据准备、首次 Canvas 绘制、绘制 P95、可见编辑到绘制、Worker 往返、公式耗时和可观察内存；没有数据时不显示虚构 FPS 或 SLA。

## 能力对照

| 性能页能力               | 当前实现                                    | 交付边界                                         |
| ------------------------ | ------------------------------------------- | ------------------------------------------------ |
| 原生 JavaScript 前端布局 | Canvas + CSS + ES module SDK                | 宿主无需 React；需给容器明确高度                 |
| 数据绑定与百万行滚动     | `ReportDataSource` + 有界 LRU + 逻辑行坐标  | 分页模式只读；未知总数先按上限滚动               |
| 合并、冻结、条件格式     | 合并索引、冻结行、条件规则静态绘制          | 规则导出时固化，不是 Excel 动态规则              |
| 公式                     | 安全解析器、依赖缓存、报表公式和常见聚合    | 不是 450+ 函数；无 VBA、动态数组和命名范围       |
| 客户端导出               | XLSX/CSV/JSON/PDF，分页源完整 CSV           | PDF 为栅格；XLSX/JSON/PDF 分页源需先形成静态报表 |
| 复杂报表布局             | 列表、多级分组小计、交叉统计                | 暂无设计器、主从模板；已有基础打印分页           |
| 行列结构编辑             | SDK 插入/删除、公式与规则范围同步、整次撤销 | 支持静态可写表；同步全簿存储扫描与受影响表快照   |

v0.7 增加稀疏行高、隐藏行列和 SUMPRODUCT 加权数组计算；Canvas 只绘制可见区域，XLSX/JSON 保留布局元数据，SDK 布局变更支持撤销重做。v0.8 PDF 支持隐藏轴、可见合并区域与原始坐标分页，新增打印版式演示和 MOD/INT，并修复隐藏轴、合并与冻结区键盘导航。v0.6 的结构语义见 [STRUCTURE.md](STRUCTURE.md)，支持与拒绝的引用语法见 [STRUCTURE-FORMULAS.md](STRUCTURE-FORMULAS.md)，调用和事件见 [SDK.md](SDK.md)。

v0.5 已提供列表/数值/长度输入规则，以及纸张、页边距、重复标题与双轴手动分页设置。输入规则只约束直接编辑格。JSON 保留完整 SDK 配置；XLSX 可双向转换受支持的常量数值/长度规则、受限内联文本列表及打印设置，超出子集时明确拒绝。类型与客户端行为差异见 [XLSX-VALIDATION.md](XLSX-VALIDATION.md)，打印兼容范围见 [XLSX-PRINT.md](XLSX-PRINT.md)。

v0.9 统一筛选、隐藏轴与合并区域的可见坐标：原合并区域只要还有可见单元格，就显示原锚点内容，编辑仍写回该锚点。`setSheetLayout` 可一次设置行高、列宽、隐藏行列和冻结行，失败整批拒绝、一次撤销恢复；布局快照不复制单元格。`setFilter` 是静态表的视图筛选，不改变数据、计算或导出范围；分页源需在数据源端筛选。接口契约见 [SDK.md](SDK.md)。

## 商业化路线

v0.10 补齐筛选后的批量交互：默认 `clipboardMode: 'visible'`，复制压缩可见轴，删除保留不可见数据，粘贴/填充按可见位置规划后一次提交。可显式切换 `all` 沿用原始矩形坐标。可见粘贴不扩展工作表，多格目标遇合并或空间不足时明确失败；这不等同于完整 Excel 剪贴板兼容。

v0.11 提供静态表多列整行排序，最多八个条件，稳定比较计算值；隐藏行默认留在原位，公式相对引用按移动距离平移。一次排序对应一次撤销，目标输入规则不允许的数据会整批拒绝。行高、隐藏、验证和打印设置保持坐标；排序范围不受文本筛选或剪贴板模式控制。详细契约见 [SORT.md](SORT.md)。

v0.12 主工作空间提供显式起止行和两级排序条件，复用 SDK 的排序计划与整批候选校验。旧排序把公式固化为数值、隐式重排全部数据的行为已替换：现在保留公式，不符合输入规则的排序整批拒绝；范围之外的表头与合计保持原位。v0.18 排序历史已改为补丁，但大数据编辑成本仍不等同于 SDK。见 [WORKSPACE-SORT.md](WORKSPACE-SORT.md)。

v0.13 主工作空间的普通编辑也复用候选校验，公式栏、Canvas 输入、粘贴、清空、填充以及合并值迁移均在提交前检查。公式栏失败提示可直接修改重试，失焦恢复已存值。工作簿与工作表创建、名称等更新自动写快照，普通单元格继续写补丁；顺序队列避免较早快照覆盖较新编辑，保存错误提供重试入口。见 [WORKSPACE-EDIT.md](WORKSPACE-EDIT.md)。

v0.15 将整数、小数、文本长度和列表规则接入工作空间的可视化编辑器，支持草稿编辑、删除、取消与一次保存。规则配置保存为元数据补丁，统一撤销与本地自动保存；不逐格校验或改写既有值，也不把配置成功视为整表数据验收。类型、范围与重叠语义沿用 SDK，详见 [WORKSPACE-VALIDATION.md](WORKSPACE-VALIDATION.md)。

v0.16 补齐单格列表输入：工作空间与 SDK 共用可搜索的 Canvas 选项浮层，支持键盘和虚拟列表，区分文本、数字与布尔值，选择后进入同一编辑事务。候选同时满足重叠规则，滚动和视图变更使旧浮层失效。当前浏览器实测受工具服务故障阻挡，验收范围与兼容限制见 [VALIDATION-PICKER.md](VALIDATION-PICKER.md)。

v0.17 改善批量编辑后的本地恢复成本与保存可靠性：日志整批回放，避免每条补丁重复复制整张表；内存读取隔离保存副本，底层写入失败保留待重试日志及顺序。主工作空间撤销仍为快照，详见 [WORKSPACE-EDIT.md](WORKSPACE-EDIT.md)。

v0.18 将主工作空间普通编辑、排序、规则与布局的历史改为前后值补丁，撤销/重做也以补丁写入保存队列；新增表、重命名和历史版本恢复使用快照。普通补丁撤销保留当前表选择和收藏状态。历史仍限制 60 步，尚未移除单表索引复制、配额统计或公式扫描，详见 [WORKSPACE-EDIT.md](WORKSPACE-EDIT.md)。

v0.19 工作空间按公式输入决定计算版本。规则、布局、样式和收藏等修改复用同步缓存与后台结果，保留进行中的请求；无公式时跳过 Worker 传输。值和公式变化、表结构变化及同 ID 文件替换隔离旧结果。每表公式目标仍上限 25,000，超出部分按需同步读取。v0.29 的 Worker 请求按不可变工作表复用未变化表值，但不是单元格级增量计算；协议细节见 [WORKSPACE-EDIT.md](WORKSPACE-EDIT.md#v029-按工作表复用计算传输)。

v0.20 工作空间后台计算采用有界队列：最多一个在执行、一个最新待发送。新输入替换过时的待发送版本，替换发生在工作簿传输之前；数据来源切换、公式全部移除与卸载取消旧请求。已发送的计算仍运行到返回，前台按需同步求值继续提供当前结果。消息版本不匹配、传输失败、Worker 错误和销毁都会结束相关 Promise 并清理监听器。详细边界见 [WORKSPACE-EDIT.md](WORKSPACE-EDIT.md#v020-后台计算队列)。

v0.21 为工作空间后台计算设置 30 秒超时。超时会终止旧 Worker，已发送请求以 TimeoutError 结束；如果存在最新未发送候选，重建 Worker 后只发送该候选。没有候选时等待下一次新请求再重建，避免无限重启和重放超时计算。计时依赖主线程事件循环，后台页面节流与主线程阻塞可能推迟恢复，不作为响应时延保证。见 [WORKSPACE-EDIT.md](WORKSPACE-EDIT.md#v021-计算超时恢复)。

v0.22 减少工作空间选区与首页统计的主线程开销。选区不超过 4,096 个逻辑格时直接检查目标坐标，大范围只遍历已存储单元格。首页记录数、非空格数与财务汇总复用计算输入来源，不因纯布局/样式/规则/收藏修改重新扫描；数值、跨表公式来源和活动表变化仍刷新相应统计。独立数据看板和编辑配额扫描尚未使用这项缓存，见 [WORKSPACE-EDIT.md](WORKSPACE-EDIT.md#v022-选区与首页统计)。

第一阶段应把 SDK 做成稳定可采购的前端包：版本化 API、React/Vue 包装、完整类型、错误码、主题令牌、浏览器兼容矩阵、许可证清单、Excel 往返语料和性能回归设备。数据权限、认证、审计和租户隔离必须由接入方后端负责，不能由浏览器控件假装提供。

第二阶段补齐成熟替代产品需要的 Excel 兼容、财务/统计函数及更广的日期和查找兼容、动态数组、更广的数据验证与结构引用兼容、透视表、图表、打印与矢量 PDF、多级报表模板、离线冲突和协作协议。

第三阶段再提供企业服务：组织与权限、审计、备份恢复、配额、监控、支持和授权计费。这些不在当前纯前端交付中，也没有在界面上虚构登录、支付或云端能力。

## 明确限制

SDK 的 `activeSheet`/`toJSON` 是显式全量快照，不能在热路径轮询。SDK 公式计算是同步路径；工作区和性能实验室的 Worker 会传输工作簿或真实数据批次，SDK 已按单元格依赖增量失效，范围订阅使用动态 AVL 矩形索引跳过不相交子树；密集重叠最坏情况下仍可能遍历大量节点，范围求值仍需读取成员，尚未接入 Worker 增量调度。实现与工作量计数见 [INCREMENTAL-CALC.md](INCREMENTAL-CALC.md)。工作区仍保留结构快照、配额计数和分析扫描，其编辑成本不等同于 SDK。

行列结构编辑是独立的同步全簿存储扫描：只遍历已有单元格，不展开逻辑空格，但会复制受影响工作表的前后快照用于历史。最多保留 10 次结构事务，超限时裁掉最早结构事务及之前历史前缀，维持后续撤销顺序。结构提交重建计算缓存，普通单格编辑仍走增量失效；当前没有百万实存单元格即时插删的保证。只读与分页数据源拒绝结构编辑，图表、透视表、外部工作簿、整行整列范围等未支持对象不会被假定已安全重写。

PDF、数据源和验收产物的具体限制记录在 [docs/PDF.md](PDF.md)、[docs/PERFORMANCE.md](PERFORMANCE.md) 和 [docs/VERIFICATION.md](VERIFICATION.md)。这些文档只记录已运行的测试和实际环境，不能替代商业 SLA 或完整兼容认证。

构建已生成依赖许可清单与预打包组件证据；当前技术清单为 `0 errors / 0 reviewItems / 0 unresolvedVendorComponents`。这只说明仓库材料与安装树通过了技术一致性门禁，仍需权利人/法务完成商业授权、专利和再分发义务复核。当前没有完整 SpreadJS/Excel 兼容认证，也没有据此承诺商业 SLA，详见 [DEPENDENCIES.md](DEPENDENCIES.md)。

v0.27 工作空间工具栏增加“行列”入口，支持指定位置/数量插入或删除，跨表公式和支持的元数据一起调整；候选校验通过后一次保存并可撤销。批注保持坐标绑定，不随格移动。工作空间快照历史与 SDK 结构历史政策分别适用，浏览器验收待完成；详见 [WORKSPACE-EDIT.md](WORKSPACE-EDIT.md)。

# 工作空间数据验证规则编辑器

v0.15 从工作空间工具栏“数据验证”打开编辑器。选中的单元格或矩形范围作为新规则的默认范围；每条规则可以指定另一段当前表内的 A1 范围，例如 `C2:C100`。支持大小写、绝对地址和反向选择，保存为规范的左上到右下矩形。单元格样式、内容和公式保持原样。

## 配置流程

1. 选中要约束的范围，点击“数据验证”。
2. 添加或选择一条规则，设置范围、规则类型、边界或允许值。
3. 设置是否允许空白，以及填报失败时显示的提示。
4. 点击“保存规则”会一并应用当前已修改的表单；要继续配置多条规则，先“添加到草稿”或“更新草稿”，再切换规则。取消或关闭弹窗放弃本次草稿。

首次打开时显示的默认整数范围只是表单预设，未编辑就保存不会新增规则；需要原样采用预设时，点击“添加到草稿”。切换规则前若当前表单有未更新的内容，会提示先更新草稿或放弃修改。

支持整数、小数、文本长度、列表四种规则。整数/小数/长度提供区间及六种单边比较；区间包含端点。“不在区间内”拒绝两个端点及中间值。每条规则最多 1,000 个列表选项，每表最多 1,000 条规则，全部列表合计最多 100,000 项。错误提示最多 500 个 UTF-16 代码单元。

列表的逐行文本模式按原样保存每行文字，不自动把 `001`、`123` 或 `true` 变成数字/布尔值。JSON 模式适用于混合类型、空字符串或含换行的列表，例如 `["待处理", "001", 10, true]`；类型必须是文本、有限数字或布尔值。列表按严格类型和值匹配。详细公式结果、空白、Unicode 长度与比较语义见 [DATA-VALIDATION.md](DATA-VALIDATION.md)。

## 保存、撤销与既有数据

整组规则在提交前校验，任一规则不合法则不更新工作簿、不增加历史、不写入本地存储。规则规划与持久化补丁只处理规则元数据，不展开矩形中的逻辑空白单元格；不替换单元格内容，不自动修正已有无效值。

一次“保存规则”对应一次撤销；撤销和重做恢复整组规则，并进入同一个顺序保存队列。保存没有变化的规则不写入、不增加撤销记录，也不清空重做历史。删除全部规则后保存是一个可撤销的清除操作。保存到本地的成功与失败由工作空间原有状态显示，失败可通过“重试保存”或 Ctrl/Cmd+S 重试。

后续公式栏、Canvas 直接编辑、粘贴与填充使用最新规则验证完整候选批次。多个重叠规则必须同时满足；规则列表顺序不代表覆盖优先级。未直接编辑的依赖公式不会持续触发强约束，导入和撤销恢复既有值也不重新强制校验。

导入的规则保留 ID、工作表绑定和重叠关系；指向其他工作表的规则不会擅自重绑定。既有规则可以具有超出当前表尺寸但位于 Excel 上限内的范围，未更改时保留。新输入的范围必须位于当前表内；分页数据源只读，不能修改其规则。

## 交付边界

这是规则编辑器，不是全表数据质量扫描器。v0.16 已接入 [Canvas 单元格选项选择器](VALIDATION-PICKER.md)，配置列表规则后可在单格内选择允许值。规则随 JSON 完整保存；XLSX 仅支持受限子集，包含混合类型列表、重叠规则等时可能明确拒绝导出，见 [XLSX-VALIDATION.md](XLSX-VALIDATION.md)。v0.18 规则修改及其撤销采用补丁历史；v0.19 进一步复用原公式计算来源，保存规则和补丁撤销/重做不再触发公式目标扫描或后台计算。保存规则的总体成本仍不等于 SDK 的百万逻辑行性能，见 [工作空间计算调度](WORKSPACE-EDIT.md#v019-按计算输入调度)。

# 客户端 PDF 导出

`workbookToPdf` / `workbookPdfBlob` 在浏览器中将活动工作表按真实网格分页绘制为 Canvas，再装配为 PDF 1.4。无需服务端、打印对话框或额外 PDF 依赖。

## 当前能力

- A4（默认）/A3/Letter，横向（默认）和纵向、四边距与双轴手动分页，真实列宽驱动横向分页，折行后的实际行高驱动纵向分页。
- 首部行/列可重复打印。默认重复冻结行；`repeatRows` / `repeatColumns` 可配置。
- 中文与 Unicode 使用浏览器系统字体渲染，背景色、文字色、字号、粗体、斜体、下划线、对齐、数字格式基本保留。
- 合并区域作为整体留在同一页，长文本折行并增加行高，不再截为 32 字符。
- 页眉显示实际行列段，页脚显示页码，公式导出为当前计算结果。
- 提供进度回调和 `AbortSignal`，页间让出浏览器执行权。

## 明确边界

这是栅格网格报表导出，不是 Excel 布局保真导出。PDF 内没有可选择文字、语义标签或屏幕阅读器结构；字体由用户浏览器的字体安装情况决定。低层导出器不直接解释条件规则；SDK export 会先固化规则命中的静态样式。当前不导出图表、图片、批注、交互表单、打印区域等尚未建模的对象。仅导出活动工作表。XLSX 导出也仅覆盖已建模的内容，不能补回这些尚未实现的对象。

默认最多 5,000 行、256 列、200,000 个矩形区域单元格、200 页。每项均可在 API 中明确配置。超过限制直接抛错，绝不静默截断。单个行、列或合并区域超过单页空间，重复标题跨合并边界，合并区域重叠或掩盖非空内容，也会明确失败。

分片数据源必须完整物化为静态工作表再导出；导出器拒绝把分页缓存当作整张数据表。PDF 装配仍需在内存保留已编码的页面，因此不用于百万行整表 PDF。大数据应按筛选后的报表范围导出或使用 CSV/XLSX。

## 与 XLSX 打印设置往返

v0.5 XLSX 导入恢复的受支持打印设置可直接由 PDF 导出消费，包括 A4/A3/Letter、方向、四边距、前导重复标题和行列手动分页；导出参数仍可覆盖工作表设置。PDF 按本产品的列宽、浏览器字体和折行重新排版，不保证与 Excel 打印页一一相同。非支持纸张、打印区域、缩放适配等设置在 XLSX 导入时明确拒绝，细节见 [XLSX-PRINT.md](XLSX-PRINT.md)。数据验证规则不会变成 PDF 输入控件，见 [XLSX-VALIDATION.md](XLSX-VALIDATION.md)。

## v0.8 隐藏轴验收

支持隐藏行列、部分可见合并区域和可见重复标题。公式读取完整数据；分页仍按原始坐标配置，隐藏区的冗余边界会合并。已用区域完全隐藏时明确失败。自定义行高按像素 × 0.75 换算，必要时为折行内容扩高。细节见 [PRINT.md](PRINT.md)。

本机 Chrome 通过生产 SDK 的“打印版式 → 导出报表”实际生成 [report-v08-visible.pdf](artifacts/report-v08-visible.pdf)：81,622 字节、1 页、A4 横向（841.89 × 595.28 point）。PDFium 完整解析并渲染；[页面图](artifacts/report-v08-visible.png) 目视确认中文、合并标题、列号跳过 B、行号跳过 6、结算合计 4,300（包含隐藏调整 -100）正确。此处隐藏是显示功能，示例主动在可见说明中展示调整金额。

新增 12 项 PDF 可见性测试覆盖双轴重复标题、手动分页映射、空可见范围、配额、1px 行高，以及 Canvas 绘制调用中的隐藏内容、合并锚点、公式和进度。

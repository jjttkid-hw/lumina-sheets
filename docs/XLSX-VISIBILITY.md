# XLSX 行列布局元数据

`Sheet.rowHeights` 按零基行号保存稀疏行高，单位为 CSS 像素（允许 1–600）。`hiddenRows` 与 `hiddenColumns` 为零基行列坐标数组。JSON/SDK 快照保存这些字段，数组和对象均复制隔离；SDK 表格元数据修改与结构编辑的撤销重做也保留它们。

XLSX 导入按 `96 / 72` 将 Excel 行高 point 转为像素，导出按 `72 / 96` 转回。超限值明确拒绝，不裁剪为另一个行高。隐藏不删除数据，不改变公式引用或计算值；隐藏状态不是数据访问权限。

导入从原始 worksheet XML 读取行高与隐藏行/列，因为 ExcelJS 的工作表模型会丢弃只有隐藏标记的空行。导出在 ExcelJS 文件生成之后补写这些空白 `<row hidden="1">`，按行号排序；不创建空单元格。仅有行列布局元数据时，也会恢复足够的逻辑行列尺寸，仍受文件导入配额限制。

本模块只处理独立行高和行列隐藏状态，不处理分组大纲、折叠按钮或工作表 hidden/veryHidden 状态。CSV 按逻辑单元格导出，包含隐藏行列。Canvas 根据可见轴绘制，v0.8 PDF 同样跳过隐藏轴；公式仍读取完整数据，部分隐藏合并区会展示原锚点内容。PDF 的详细分页与行高语义见 [PRINT.md](PRINT.md)。

`tests/io.test.ts` 使用真实 XLSX 验证空白隐藏行、隐藏列、稀疏行高、元数据超出存储区域以及行高拒绝边界；`tests/structure-edit.test.ts` 验证插删移动和删除范围清理；`tests/sdk.test.ts` 验证元数据隔离、撤销重做与原子参数拒绝。
